# Datasets

| Directory | Contents |
|---|---|
| `ViNumQA/` | The dataset this project is built on — VLSP 2025 NumQA shared task. Core splits plus every reasoning-trace-distillation variant. **See `ViNumQA/README.md` for the full file-by-file breakdown.** |
| `FinQA/` | Original English FinQA dataset (Chen et al., 2021) — the source dataset ViNumQA's format is based on. Reference only, not used directly in any notebook. |

For which file to use in a given experiment, and what each reasoning-trace
variant means, start with `ViNumQA/README.md`.
